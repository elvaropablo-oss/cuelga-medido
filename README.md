# CuelgaMedido

Calculadoras estáticas en español para trasladar cuadros y cuadrículas de marcos a marcas medibles en la pared.

## Verificación

```text
npm run verify
```

El sitio se genera en `dist/` y se publica mediante GitHub Pages.

## Alcance

La V1 cubre marcos rectangulares iguales, filas y cuadrículas. No elige fijaciones ni evalúa la resistencia de la pared.
