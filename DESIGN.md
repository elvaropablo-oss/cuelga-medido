# Design direction

**North star:** a contemporary gallery installation plan where every frame, centre line and hanging mark feels deliberate.

The palette is gallery white `#fff`, warm wall grey `#f2f1ed`, charcoal `#161616`, installation blue `#3448d8` and laser red `#ef493d`. Baskerville-style serif headlines create a catalogue voice; compact monospace labels carry measurements.

Heroes pair editorial copy with a framed measurement diagram. Directory cards become physical frames with varied placement. Results use blue mounting boards, black frames and red offset marks. Layouts collapse cleanly below 840 px; focus uses laser red, motion is limited to a two-pixel button lift and print removes decoration.
